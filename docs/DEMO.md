# אתר הדמו: להראות את האתר ללקוחות עם לינק

פרויקט Vercel אחד, נפרד מהלקוחות, שמראה את הזוג לדוגמה (נועה ויואב). לכל מתעניין יוצרים לינק אישי שעובד כמה ימים.

## הקמה (פעם אחת)
1. Vercel → Add New → Project → אותו ריפו. שם לדוגמה: `our-world-demo`.
2. Settings → Environment Variables:
   - `CLIENT` = `demo`
   - `DEMO` = `1`
   - `SESSION_SECRET` = מחרוזת אקראית ארוכה (`openssl rand -base64 32`)
   - `ADMIN_PASSWORD` = הסיסמה **שלך** (ממנה יוצרים לינקים)
   - `PARTNER_PASSWORD` = משהו ארוך שאף אחד לא צריך לדעת
   - כדי לקבל הודעה כשמישהו פותח לינק: `NTFY_TOPIC` (או וואטסאפ / מייל, כמו בלקוח רגיל)
   - Upstash לא חובה. בלעדיו אף אחד לא יכול לשמור כלום, וזה בדיוק מה שרוצים בדמו.
3. Deploy.

## יצירת לינק
נכנסים לאתר הדמו עם `ADMIN_PASSWORD` ופותחים את עמוד הניהול. בכרטיס **"לינקים לדמו"** בוחרים:
- למי הלינק (שם, בשביל ההודעה שתקבל)
- כמה זמן הוא עובד: יום, 3 או 7
- **"לינק לאתר שלה"**: מה שבת הזוג רואה. **"לינק לעמוד הניהול"**: מה שהמזמין מקבל.

הלינק מועתק לבד, ואפשר לשלוח אותו בוואטסאפ ישר מהכרטיס.

## מה מי שמקבל לינק יכול לעשות
- להסתכל על הכל, כמו בשבוע הראשון של זוג אמיתי. למעלה מופיעה תווית "אתר לדוגמה".
- **לא** לשנות כלום: השרת חוסם כל שמירה של אורח.
- **לא** ליצור לינקים, ו**לא** להוריד גיבוי.
- כשהזמן נגמר, הלינק מוביל לדף "הלינק הזה כבר לא בתוקף".

## הגנה מהעתקה
- **בינה מלאכותית וסקריפטים חסומים** (`api/_lib/bots.ts`): Claude, ChatGPT, Perplexity, curl, דפדפנים אוטומטיים ועוד מקבלים 403. מי שמדביק את הלינק בצ׳אט עם AI ומבקש להעתיק את האתר, מקבל דף ריק.
- **אין קוד מקור באתר:** הקוד מכווץ (minified) ובלי source maps, ואין באתר שום קובץ גיבוי עם קוד.
- **לא מופיע בגוגל:** `robots.txt` וכותרת `X-Robots-Tag: noindex, noai`.
- **אי אפשר להטמיע אותו** באתר אחר (`X-Frame-Options: DENY`).
- **הלינק פג לבד,** ואתה יודע מתי ומי פתח אותו.

**מה אי אפשר למנוע:** מה שמוצג בדפדפן אפשר תמיד לצלם מסך או לשמור ידנית, וגם עקיפה של החסימות דורשת ידע. החסימה סוגרת את הדרך הקלה. מה ששווה כסף נשאר אצלך: השרת, ההתאמה האישית לכל זוג והקוד המלא בריפו הפרטי.
