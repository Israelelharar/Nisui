# Velorah — Fight Arena Landing Page

A single-page, fight-game-themed hero site built with **React + Vite + TypeScript + Tailwind CSS + shadcn/ui**.

## Features

- Fullscreen looping background video hero (autoplay, muted, playsInline) with a fight/combat clip
- Glassmorphic navigation bar with the `.liquid-glass` effect
- Cinematic typography using **Instrument Serif** (display) + **Inter** (body) from Google Fonts
- Dark, high-contrast fight-arena color theme (near-black background, crimson "ember" accent)
- Fade-rise entrance animations on the hero content
- Additional sections: fighter roster, game modes, legacy/about, and footer

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build

```bash
npm run build
npm run preview
```

## Tech stack

- [Vite](https://vite.dev/)
- [React 19](https://react.dev/) + TypeScript
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)-style components (Button, built on `class-variance-authority` + Radix Slot)
- [lucide-react](https://lucide.dev/) icons
