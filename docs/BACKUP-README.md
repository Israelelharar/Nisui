# הגיבוי של האתר שלכם

בקובץ הזה שמור כל מה ששייך לכם:

| בתוך ה־zip | מה זה |
|---|---|
| `content/` | הטקסטים, המכתבים, הסיפור, התמונות וכל מה שנכתב בשבילכם |
| `data/site-data.json` | מה שנשמר באתר עד יום הגיבוי: החיה, האלבום, הציורים, הפתקים שנפתחו, היומן וההגדרות |
| `backup-manifest.json` | מתי הגיבוי נוצר |

**אם משהו קרה לאתר:** שלחו את הקובץ הזה למי שבנה לכם את האתר, והוא יחזיר הכל בדיוק כמו שהיה.

כדאי לשמור עותק אחד בדרייב ועוד אחד במייל.
