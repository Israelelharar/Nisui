# לקוח חדש: מהשאלון ועד אתר באוויר

כל זוג הוא תיקייה אחת ב־`clients/<slug>/`, ופרויקט Vercel אחד שמצביע על אותו ריפו עם `CLIENT=<slug>`.
הקוד משותף לכולם. כשמשפרים משהו, כל הלקוחות מקבלים אותו בפריסה הבאה שלהם.

## 1. השאלון ללקוח (מה לבקש)

**חובה**
- השם שלו ושלה (או שלו ושלו, שלה ושלה) וכתובת האתר שירצו. מי מזמין את האתר (הוא מקבל את הניהול) ולמי הוא מיועד.
- מתי התחילו להיות ביחד (תאריך).
- איזה חלקים רוצים באתר (ראו טבלה למטה), או אחת מהחבילות: **מלא**, **מכתבים ותמונות**, **רק תמונות**.

**מומלץ**
- מתי ואיפה הכירו ("בחתונה של רוני").
- יום הולדת של מי שמקבל/ת את האתר (לועזי, ואם רוצים גם עברי).
- מספר טלפון של המזמין (לכפתור "אני צריכה אותך" בוואטסאפ ובשיחה).
- 10–40 תמונות, ולכל אחת משפט קצר (מצחיק או מרגש, לא תיאור).
- כינויים (5–20).
- אם רוצים מכתבים: מכתבים/פתקים/שירים שכתבו אחד לשנייה. אחד נפתח כל יום.
- חיית מחמד וירטואלית: **שרקן, חתול, כלבלב או ארנבון**, ושם מוצע.
- הסיפור שלהם בכמה נקודות (לציר הזמן), מקומות שהיו בהם (למפה), דברים שעוד רוצים לעשות.
- בדיחות פרטיות, מילים שהמציאו, שובר/הבטחה שרוצים לתת.
- פלייליסט ספוטיפיי משותף (קישור).
- ייצוא צ׳אט וואטסאפ (רק אם רוצים "ספר" ו"היום לפני שנה"; Claude כותב מהם פרקים).

## 3. בניית התיקייה

1. מעתיקים את `clients/_template` ל־`clients/<slug>` (אותיות קטנות באנגלית, למשל `noa-yoav`).
2. `profile.json`: `slug` (אותו שם כמו התיקייה), כותרת, שמות, מגדר (`"m"`/`"f"`) וטלפון של המזמין.
3. `index.ts`: תאריכים, חבילה (`presets.full` / `presets.lettersAndPhotos` / `presets.photosOnly`) והחיה.
4. תמונות: `python3 scripts/add-photos.py <slug> <תיקייה-עם-התמונות>`. הסקריפט מכין את הקבצים ומדפיס את הרשימה ל־`content/photos.ts`. כותבים לכל תמונה כיתוב.
5. `content/index.ts`: כל השאר. הדוגמה המלאה היא `clients/demo/content/`. כל הטקסטים נכתבים בקול של המזמין, לפי המגדר של שניהם.
6. בודקים:
   ```bash
   CLIENT=<slug> npm run dev       # http://localhost:5173 (?at=2026-11-05T08:00 לראות יום אחר)
   CLIENT=<slug> npm run build
   npm run check:leaks
   ```

## 4. העלאה לאוויר (Vercel)

1. Vercel → Add New → Project → אותו ריפו. שם הפרויקט = הכתובת (`noa-yoav.vercel.app`).
2. Storage → Upstash for Redis → Free → Connect. (או מסד אחד משותף ו־`KV_PREFIX` שונה לכל לקוח.)
3. Settings → Environment Variables:
   - `CLIENT` = `<slug>`
   - `SESSION_SECRET` = מחרוזת אקראית ארוכה (`openssl rand -base64 32`)
   - `ADMIN_PASSWORD`, `PARTNER_PASSWORD` = הסיסמאות (שולחים למזמין בלבד)
   - התראות (לבחירה): `NTFY_TOPIC`, או `NOTIFY_WHATSAPP` + `CALLMEBOT_APIKEY`, או `NOTIFY_EMAIL` + `RESEND_API_KEY`
4. Deploy. נכנסים עם סיסמת המזמין ל־`/admin`, בודקים, ומאפסים ב"לאפס ולהתחיל מאפס" אם נכנסתם עם הסיסמה שלה.
5. מוסרים למזמין: הכתובת, שתי הסיסמאות, והסבר קצר על עמוד הניהול (עריכת יום, פגישה הבאה, עיצוב, גיבוי).

## 5. אחרי המסירה

- תוכן חדש (מכתבים, פרקים, תמונות): מוסיפים בתיקייה של הלקוח ופורסים.
- המזמין יכול לבד: הודעה מיוחדת ליום, פתק נוסף, ברכה, פגישה הבאה, עיצוב, גיבוי, מתנות לחיה.
- "להעתיק ל־Claude" בעמוד הפגישות: מה שהיא כתבה ביומן נהיה פרק בספר.
